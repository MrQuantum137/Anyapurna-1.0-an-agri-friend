# Anyapurna 1.0: Agri-Friend
Crop Yield Prediction Model for Indian Farmers
Anyapurna 1.0 is a Machine Learning project designed to help farmers in India—specifically in regions like Uttar Pradesh—predict crop yields based on environmental and historical data. This project was developed as part of my journey to solve daily challenges through AI and Data Science.

The Problem
Many farmers in India struggle with unpredictable crop yields due to changing environmental factors. This tool aims to provide a data-driven "friend" to help them make better decisions.

Technical Overview
Language: Python

Environment: Jupyter Notebook

Approach: Classical Machine Learning (Data Preprocessing, Feature Engineering, and Model Training).

Goal: To provide a simple, scalable prediction engine for agricultural planning.

Current Status
This model is a functional prototype. I am currently expanding my skills in XGBoost and specialized ML to apply similar logic to healthcare (Dental Triage) for the Harvard HSIL Hackathon 2026.
